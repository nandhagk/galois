# Minimal contract fixes

Status: in force

A minimal fix to a public statement is made and reported with its old and new text for review
(formerly ruling C14). A minimal fix is a typo, an aligned name, an added implicit argument or
coercion, or an obviously missing well-formedness premise. A fix that changes the meaning of a
statement needs an owner ruling.

## Why

Reviewers can distinguish mechanical repairs from changes to guarantees.
